# Images

Place real, consensually-shared photos here (e.g. `memory-1.jpg`) and reference
them from `src/content/siteContent.ts` by setting the matching memory's
`imageSrc` to a path like `/images/memory-1.jpg`.

Do not add images without the recipient's knowledge and consent. Leave
`imageSrc: null` in the content file to show a neutral decorative placeholder
instead of a photo.
